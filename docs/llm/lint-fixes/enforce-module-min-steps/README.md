# `enforce-module-min-steps`

A Module method accepts 0 or 1 Step. This is a **warning**. It exists so `enforce-no-step-loop-internal-function` extracts do not become one-step ceremony Modules.

Read the matching recipe before editing.

| Preference | Recipe | Use when |
| :--- | :--- | :--- |
| preferred (real sequence) | [expand-accept-chain](expand-accept-chain/) | The method should own two or more sibling Steps. Add them to the flat try. |
| alternative (only one concern) | Keep the work in the Step. Do not use a Module. | |

Rule guide: [`../../rules/enforce-module-min-steps.md`](../../rules/enforce-module-min-steps.md)
